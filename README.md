# Fix My Code Challenge

My debugging exercises for Holberton School. The solutions are in the [challenge](challenge/) folder.

## Tasks

| Task | Language | Fix |
| --- | --- | --- |
| FizzBuzz | Python | Check multiples of both 3 and 5 first. |
| Print square | JavaScript | Read the size as a decimal number. |
| Sort | Ruby | Insert each number at the correct position. |
| User password | Python | Store and compare the same password hash. |
| Doubly linked list | C | Update node links before freeing the deleted node. |

## Requirements

Python 3, Node.js, Ruby and GCC.

## Source

The starting code is from [Holberton School](https://github.com/holbertonschool/0x00-Fix_My_Code_Challenge).
